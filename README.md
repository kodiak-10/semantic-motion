# Semantic Motion Skill

通用科普动画制作 Skill，支持二维与基础 3D 效果。当前版本：**v0.12.0-alpha.1（实验版）**。

## 下载完整 Skill

[下载 semantic-motion-v0.12.0-alpha.1.zip](https://github.com/kodiak-10/semantic-motion/raw/refs/heads/main/semantic-motion-v0.12.0-alpha.1.zip)

这是完整、可编辑的源码包，包含 54 个文件：SKILL.md、内容规划、动画引擎、三维几何模块、检查脚本、依赖锁定文件、使用说明和测试数据。**没有 MP4、配音或 Jev 视频。** Jev 和天空主题仅作为可重建的测试数据。

当前仓库通过 ZIP 分发源码；请下载上面的文件后解压，不要把仓库根目录直接当成已展开的 Skill 安装。

## 如何使用

1. 下载并解压 ZIP，得到 `semantic-motion` 文件夹。
2. 用支持代码执行的 AI 助手打开这个文件夹，让它读取 `SKILL.md`。
3. 输入自己的主题，例如：

> 按本目录 SKILL.md，制作“为什么冰会浮在水上”的 90 秒科普动画，面向普通大众，16:9，无声。先解释基本概念，再演示机制与边界；用适合的二维与立体效果讲清楚，输出视频、讲稿、字幕和检查结果。

AI 需要先核实资料、写讲稿和设计分镜。它不是只换标题的模板，也不保证任意主题自动生成高质量成片。

## 检查是否能运行

安装 Node.js 22.18 或更新版本，在解压出来的文件夹运行：

```sh
npm ci
npm run setup
npm run check
npm run demo:3d
```

最后一条命令生成 `out/spatial.mp4`，用于检查 3D 模块。包里没有预先打包的视频。详细说明见解压后的 README.md。

基础 3D 支持立方体、球体、透视、三轴旋转和方向光，不包含人物骨骼或复杂模型导入。默认中文、1920×1080、无声，讲稿与字幕独立导出。
